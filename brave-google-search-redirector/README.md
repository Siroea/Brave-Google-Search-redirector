# 🚀 Brave Google Search Redirector (拡張機能)

Braveブラウザにおいて、デフォルト検索エンジンでGoogleが選択・追加できなくなってしまった問題に対応するための専用Chrome/Brave拡張機能です。

アドレスバー（オムニボックス）からYahoo!などの検索が実行された際、**自動的・即座にGoogle検索へ強制転送**します。

---

## 🛠️ インストール手順 (簡単3ステップ)

1. **Braveの拡張機能ページを開く**
   - Braveのアドレスバーに `brave://extensions` と入力してEnterを押すか、右上のメニュー (≡) → **拡張機能** → **拡張機能の管理** を開きます。

2. **デベロッパー モードをONにする**
   - 画面右上にある **「デベロッパー モード」 (Developer mode)** のトグルスイッチを **ON** にします。

3. **拡張機能を読み込む**
   - 左上に表示される **「パッケージ化されていない拡張機能を読み込む」 (Load unpacked)** ボタンをクリックします。
   - 以下のフォルダを選択してください:
     ```
     C:\Users\siroe\.gemini\antigravity\scratch\brave-google-search-redirector
     ```

これで導入完了です！🎉

---

## 💡 機能と使い方

### 1. アドレスバー検索の自動転送
- デフォルト検索エンジンがYahoo!等に固定されていても、アドレスバーにキーワードを入力してEnterを押すだけで、自動的に **Google検索結果画面** へリダイレクトされます。
- Yahoo!のトップページ (`yahoo.co.jp`) の閲覧自体は妨げず、検索実行時のみ転送します。

### 2. ショートカット検索 (`g` キーワード)
- アドレスバーで `g [スペース] キーワード` (例: `g Brave拡張機能`) と入力してEnterを押すと、直接Google検索を実行できます。

### 3. コントロールパネル (ポップアップ画面)
- ツールバーの拡張機能アイコンをクリックすると設定画面が開きます。
  - **ON/OFF 切り替え**: 必要に応じて一時的に転送をオフにできます。
  - **Googleドメイン選択**: Google Japan (`.co.jp`) と Google Global (`.com`) を切り替え可能。
  - **統計カウンター**: これまでに転送した検索回数をカウント表示。
  - **クイック検索**: 設定画面から直接Google検索を実行。

## 📂 ファイル構成
- `manifest.json` : Manifest V3 拡張機能の構成ファイル
- `background.js` : 検索リクエストを検知し即座に転送するサービスワーカー
- `content.js` : 転送漏れを防止するセーフティスクリプト
- `popup.html` / `popup.css` / `popup.js` : 高機能コントロールパネル画面
- `icons/` : アイコン画像 (16x16, 48x48, 128x128)
